# 🛒 Multipage Grocery Website Using React & Tailwind CSS

A front-end grocery shopping application built with React and Tailwind CSS. This project demonstrates a clean, responsive, multipage layout with routing, sliders, and UI enhancements — ideal as a practice project or starter template.

---

## 📖 About

This project is a **frontend-only** grocery web application built with React and Tailwind CSS. It features multiple pages (Home, Fruits, Dairy, Seafoods, All Products, About, Contact, Process) and uses **React Router DOM** for navigation. UI elements are enhanced with **React Icons**, and product carousels/sliders are powered by **Swiper JS**. No backend or API integration is included — it’s purely for UI, routing, and design practice.

---

## ✨ Features

- Multipage navigation (client‑side routing)  
- Responsive layout for desktop, tablet, mobile  
- Product sliders / carousels using Swiper JS  
- Use of React Icons for intuitive and consistent UI  
- Clean and modern styling with Tailwind CSS  
- Reusable component structure and modular design

## 🧱 Setup & Installation

1. **Clone the repository**  
   ```bash
   git clone https://github.com/MahiaMosarrat/Multipage-Grocery-Website-Using-React.git
2. **Navigate into project**  
   ```bash
   cd Multipage-Grocery-Website-Using-React
3. **Install dependencies**  
   ```bash
   npm install
4. **Run in development mode**  
   ```bash
    npm run dev
  
5. Visit http://localhost:3000 (or as your dev server indicates) in your browser.
